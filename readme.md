# 📊 학생 생활 만족도 인터랙티브 대시보드

이 프로젝트는 학생들의 학교생활 데이터(공부시간, 수면시간, 스마트폰 사용시간, 만족도, 한줄의견 등)를 담은 CSV 파일을 업로드하여, 데이터를 정제하고 다양한 시각화 차트로 분석해 주는 인터랙티브 웹 대시보드입니다. Python의 `Streamlit` 프레임워크를 기반으로 작성되었습니다.

## 🌟 주요 기능

1. **데이터 업로드 및 자동 정제**: CSV 파일을 업로드하면 결측치 및 이상치가 있는 데이터를 자동으로 제외하고, 제외된 건수를 안내합니다.
2. **데이터 미리보기**: 상위 5개(Top 5)의 데이터를 표 형태로 미리 확인할 수 있습니다.
3. **학과별 인터랙티브 필터링**: 특정 학과를 선택하면 대시보드 내의 모든 데이터(평균 점수, 그래프, 텍스트 분석)가 해당 학과 기준으로 즉시 연동되어 변경됩니다.
4. **요인별 상관관계 산점도**: 공부시간, 수면시간, 스마트폰 사용시간이 학교생활 만족도와 어떤 관계가 있는지 `Plotly`를 이용한 반응형 산점도로 보여줍니다.
5. **한줄의견 텍스트 및 감성 분석**: `Kiwi` 형태소 분석기를 사용하여 학생들의 한줄의견에서 의미 있는 단어(표제어)만 추출합니다.
    * 긍정/부정 단어 등장 횟수 분석
    * 자주 등장하는 단어 상위 10개 막대그래프 시각화
6. **안정적인 워드클라우드**: `WordCloud` 패키지를 사용하되, 특정 파이썬 버전이나 환경 오류(PIL 충돌 등) 발생 시 자동으로 `Matplotlib`을 이용한 우회 렌더링을 수행하여 절대 프로그램이 멈추지 않도록 설계되었습니다.

## 🛠 필수 준비물 (Prerequisites)

* **Python 3.8 이상** 권장
* **한글 폰트 파일**: 워드클라우드 및 차트 한글 깨짐 방지를 위해 `NanumGothic.ttf` 파일이 `one.py`와 같은 폴더에 있어야 합니다.

## 📦 설치 방법 (Installation)

1. 터미널(또는 명령 프롬프트)을 열고 프로젝트 폴더로 이동합니다.
2. 아래 명령어를 입력하여 필요한 라이브러리들을 한 번에 설치합니다.

```bash
pip install -r requirements.txt
```

*(참고: `kiwipiepy` 형태소 분석기는 기존 KoNLPy와 달리 별도의 Java 설치가 필요하지 않아 매우 편리합니다.)*

## 🚀 실행 방법 (Usage)

터미널에서 아래 명령어를 입력하여 대시보드를 실행합니다.

```bash
streamlit run one.py
```

명령어를 실행하면 기본 웹 브라우저가 열리며 대시보드 화면이 나타납니다. 화면 안내에 따라 준비된 CSV 파일(`campus_life.csv` 등)을 업로드하여 기능을 확인하세요.
